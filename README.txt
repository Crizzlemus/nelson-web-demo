Sitio web de campaña - Nelson Carmona Lopera (Cámara 107)

Estructura:
- index.html
- styles.css
- script.js
- /assets (imágenes suministradas)

Uso:
1) Abre index.html en tu navegador, o súbelo a cualquier hosting (Netlify, Vercel, GitHub Pages).
2) Si quieres que el formulario envíe datos de verdad, cambia el JS (script.js) para apuntar a un backend (Google Forms, SheetDB, Firebase, etc.).
3) Si los enlaces de redes sociales requieren URL exacta diferente, edítalos en index.html.
